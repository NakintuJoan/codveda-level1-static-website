# Codveda Technologies - Web Development Internship Project

## Project Description
This is a professional, multi-page static website built using only HTML and CSS as part of the Codveda Technologies Web Development Internship (Level 1, Task 1). The website showcases a fictional web development company with a modern, responsive design.

## Features
- **Home Page (index.html)** - Hero section, services showcase, call-to-action
- **About Page (about.html)** - Company information, mission/vision/values, why choose us
- **Contact Page (contact.html)** - Contact information and static contact form
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI** - Clean design with blue, white, and dark navy color scheme
- **Semantic HTML** - Proper use of HTML5 semantic elements
- **Pure HTML & CSS** - No JavaScript, frameworks, or libraries used

## File Structure
```
website/
├── index.html      # Home page
├── about.html      # About page
├── contact.html    # Contact page
├── style.css       # Shared stylesheet with all styles and responsive design
└── README.md       # Project documentation
```

## Technologies Used
- HTML5 (Semantic elements: header, nav, main, section, article, footer)
- CSS3 (Flexbox, Grid, Media Queries, Transitions)

## Color Scheme
- **Primary Blue**: `#2563eb` - Buttons, links, accents
- **Dark Navy**: `#0f172a` - Navigation, footer, headings
- **White**: `#ffffff` - Backgrounds
- **Light Grays**: `#f8fafc`, `#e2e8f0`, `#cbd5e1` - Sections and subtle elements
- **Text Colors**: `#1e293b`, `#475569`, `#64748b` - Body and secondary text

## How to Run the Website
1. Download or clone this project to your local machine
2. Navigate to the project folder
3. Open `index.html` in your preferred web browser
   - Double-click the file, or
   - Right-click → Open with → Your browser, or
   - Use a local server (e.g., VS Code Live Server)

## Testing the Website
### Browser Testing
- **Desktop**: Test at full screen resolution (1920x1080 or similar)
- **Tablet**: Use browser dev tools to simulate tablet sizes (768px and below)
- **Mobile**: Use browser dev tools to simulate mobile sizes (480px and below)

### What to Check
- [ ] Navigation links work correctly between all three pages
- [ ] All sections display properly on different screen sizes
- [ ] Images load correctly
- [ ] Contact form layout displays (note: form is static, doesn't submit)
- [ ] Hover effects work on buttons and cards
- [ ] Text is readable at all screen sizes

### Browser Developer Tools
1. Open the website in Chrome/Firefox/Edge
2. Press `F12` to open Developer Tools
3. Click the device toolbar icon (or `Ctrl+Shift+M` / `Cmd+Shift+M`)
4. Test different device presets and custom sizes
